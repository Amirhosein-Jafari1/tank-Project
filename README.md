# Tank Project
TANK Project is a modern and responsive automotive landing page featuring TANK 300 and TANK 500.
It includes promotional offers, vehicle features, pricing, image galleries, and interactive UI elements.
The project focuses on clean UI, responsive design, reusable components, and modern CSS techniques.

## 📥 Installation & Run
### Prerequisites
- Git
- Node.js
- npm

### 1. Clone the Repository
```bash
git clone https://github.com/Amirhosein-Jafari1/tank-Project.git
```

### 2. Install the dependencies:
```bash
npm install
```

### 3. Start Tailwind CSS:
```bash
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```

### 4. Open `index.html` with Live Server in VS Code.
